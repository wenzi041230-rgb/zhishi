# 飞书多维表格只读接入

## 用户目标

在 Codex 接入飞书多维表格，实测指定数据表和视图的读取权限。

## 已确认结论

- 飞书官方 CLI 可通过浏览器初始化具名应用配置。启用数据表字段和记录的只读接口权限、授予应用目标资源的访问权限后，可以用应用身份访问指定表。
- 表格协作授权、应用接口权限和用户 OAuth 属于独立的授权环节。应用身份的接口权限缺失表现为 app_scope_not_applied，用户身份缺少 OAuth 凭据表现为 token_missing。
- 本地 MCP 对接飞书官方 CLI，限制目标表和视图，公开两个只读工具。通过 Codex 注册配置发起 MCP 握手并读取字段及一条记录，验证了目标资源的应用身份只读访问。
- CLI 的记录 JSON 返回 record_id_list 和 data，验收时应检查记录标识与记录数据均存在。安装成功、工具可列出和开放平台授权均只证明相应环节。

## 待确认或待实测

既有 Codex 会话的工具列表可能需要重新载入。未测试写入。新接入应按实际任务重新确认目标与所需权限。
