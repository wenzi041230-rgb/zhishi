# PADS 滚轮缩放排查

## 已确认结论

- PADS Layout VX.2.4 的安装手册第 65 至 66 页区分滚轮和中键。画布上 Ctrl + 滚轮用于缩放。按住中键向斜上或斜下拖动可框选放大或缩小。PgUp 和 PgDn 也可调整视图。
- 当前 PADS Layout 用户配置中，Ctrl + 滚轮与中键拖动的绑定存在。只核对了配置，未实测物理鼠标输入。
- 查到历史 PadsHelper 快捷方式的目标文件已不存在，当前也未发现助手进程。若此前单独滚动滚轮即可缩放，原有助手未运行是一个可能原因。[PadsHelper 功能页](https://padshelper.weebly.com/features.html)

## 可复用知识

- 若原生手势也失效，可比较快捷键与鼠标行为，再检查 Tools → Customize → Keyboard and Mouse 中对应的单个绑定，避免全量重置定制设置。
