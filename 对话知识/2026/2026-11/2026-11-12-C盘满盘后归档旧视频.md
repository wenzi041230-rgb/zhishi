# C 盘满盘后归档旧视频

## 用户目标

再次清理 Windows 系统盘，恢复可用空间。

## 已确认结论

- 本轮开始时 C 盘可用空间为 0 字节。上次原位压缩后曾剩约 1.55 GiB，较小余量很快耗尽。
- 找到一份数月未修改的独立视频文件，约 6.58 GiB。用 Windows 文件移动功能归档到空间充足的 D 盘，核对了源路径已腾空、目标大小及迁移前后 SHA-256 一致，归档目录保存了恢复清单。
- 归档后 C 盘可用约 6.6 GiB。WPS 自动备份、语音聊天客户端和聊天资料近期有写入。近期写入统计会计入已有文件改写，无法单独证明净增长量。这些应用资料和工作目录仅做盘点。

## 可复用知识

- 清理前可检查用户主目录里的大文件，常规的桌面、下载及文档目录扫描会漏掉这部分。
- 归档可独立打开且用途明确的大文件时，先验证目标盘空间和实际路径，计算源文件哈希，移到目标盘后核对源目标状态和哈希，保存本地恢复清单。盘面可用空间应在操作后独立测量。
