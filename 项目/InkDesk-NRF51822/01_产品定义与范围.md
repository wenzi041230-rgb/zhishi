# 产品定义与范围

## 一句话定位

让手机里的重要信息在桌面长期可见、但不打扰人的三色墨水信息牌。

## 核心分工

- 手机：编辑、联网、天气、中文字体、照片处理、400×300 最终预览、历史和备份。
- 设备：BLE 接收、状态反馈、双平面写入、全刷、时钟和安全升级。
- 墨水屏：断开手机后保持最后画面，不承担高频动画或实时信息流。

## MVP 闭环

`绑定设备 → 同步时间 → 选择模板 → 编辑 → 最终预览 → 发送 BW/RED → 全刷 → SHOW_OK → 历史复用`

MVP 默认模板：Today、时钟、便签、照片卡；日历天气可由手机生成静态图后发送。

## 产品原则

1. 离线优先：编辑、历史和模板默认保存在手机本地。
2. 预览即所得：发送前必须看到最终 400×300 黑/红双平面效果。
3. 状态透明：连接、传输、刷新、失败和 DFU 都有明确状态。
4. 可靠优先：三色内容只承诺全刷。
5. 硬件能力诚实：没有 ADC 就不显示电量百分比；无法检测 5 V 就不声称“供电正常”。
6. 成功以设备回复为准：只有 `SHOW_OK` 才是显示完成。

## 明确不做

- 不做视频、秒级通知、滚动信息流和持续高频刷新。
- MVP 不强制注册云账号。
- 当前硬件不宣传电池续航、电量百分比或远距离 OTA。
- 不把本地记录冒充设备实时画面回读。

## 版本边界

| 版本 | 重点 |
|---|---|
| MVP / v1.0 | 单设备、真实 BLE、时间同步、Today/文字/图片发送、全刷、状态、诊断、近场 DFU Beta |
| v1.1 | 定时发送、收藏、答案之书、外置 Flash 缓存、开发者诊断、实验性黑白动画 |
| V2 硬件 | 电池与充电、电量采样、正式电源入口、天线优化、量产测试点、外壳与更多按键 |
