# VCClient 安装与启动验证

## 用户目标

在 Windows 11 电脑上安装一个可直接启动的 VCClient 实时 AI 变声器。

## 已确认结论

- 软件按 w-okada 的 VCClient（实时 AI 变声器）理解，并从项目 README 指向的官方 Hugging Face 仓库下载。
- 当前设备使用 Intel Arc Graphics，因此选择 `vcclient_win_std_2.0.78-beta.zip`。项目说明表明 Windows 标准版可使用 CPU 或 DirectML，适合 Intel/AMD GPU；不采用仅面向 NVIDIA 的 CUDA 包。
- 官方压缩包大小为 `423217051` 字节，SHA-256 为 `69c275e6ab4d2bf85ce61c0e1a61bd0f57267ca5914eeb26ac840184ee2724b8`；本地下载文件哈希完全一致。
- 程序安装在 `E:\VCClient\vcclient_win_std_2.0.78-beta\`，避免占用空间紧张的系统盘。
- 首次启动已完成 RVC 模块与初始样例下载；程序成功监听 `18000` 端口，`http://127.0.0.1:18000/` 与 `/docs` 均返回 HTTP 200。
- Windows 桌面已创建 `VCClient` 快捷方式，可双击启动。

## 决策与依据

- 最初考虑过 `vcclient_win_dml_2.1.4-alpha.zip`，但它约 2.94 GB 且为 alpha。复核官方 README 后确认标准版同样支持 DirectML，于是改用体积更小、风险更低的 `2.0.78-beta`。
- 放弃的 DML alpha 未完成下载文件已删除，可从官方仓库重新下载，不影响最终安装。

## 操作与产物

- 下载保留：`E:\VCClient\downloads\vcclient_win_std_2.0.78-beta.zip`
- 安装目录：`E:\VCClient\vcclient_win_std_2.0.78-beta\dist\`
- 主程序：`dist\main.exe`
- 官方启动入口：`dist\start_http.bat`
- 本地界面：`http://127.0.0.1:18000/`
- API 文档：`http://127.0.0.1:18000/docs`

## 待确认或待实测

- 只确认了来源、哈希、模块下载、进程、端口和 HTTP 页面；尚未连接实际麦克风、音频输出或 RVC 模型进行实时变声效果与延迟测试。
- `main.exe` 没有 Authenticode 数字签名。官方文件页将该包标为 Safe 且未发现异常 pickle 导入；第三方沙箱的较高行为分数主要来自 PyInstaller 解包、加载自带 DLL 和读取系统区域设置，报告中未观察到网络请求，但不能替代本机杀毒扫描。
- 程序默认监听 `0.0.0.0:18000`。在不受信任网络中应确认 Windows 防火墙没有放行入站访问，且不要将该端口映射到公网。

## 可复用知识

- Intel/AMD 显卡优先从官方说明确认标准包是否已包含 DirectML，不要仅根据文件名下载体积更大的专用 alpha 包。
- 对无数字签名的大型 PyInstaller 程序，至少应校验官方 SHA-256、检查公开沙箱报告，并明确“服务能启动”不等于“实际音频链路可用”。
- VCClient 首次启动会额外下载约 2 GB 的模块和样例；端口尚未监听时应先查看下载日志，不能立即判断启动失败。
