# C盘清理盘点

## 用户目标

清理 C 盘并释放可用空间，同时避免误删工程资料、知识库和路径敏感环境。

## 已确认结论

- C 盘容量约 210 GB，盘点开始时仅剩约 0.21 GB；后续系统状态变化后约剩 1.68 GB，仍处于高风险低空间状态。
- `C:\Users\CLX\AppData\Local\Temp` 约 7.99 GB，主要是旧的临时解压和安装目录。
- `C:\Users\CLX\Downloads` 约 3.98 GB，包含固件、PCB、测试报告、CAD 安装包等工程资料，不应按文件名批量删除。
- C 盘根目录 `hiberfil.sys` 约 12.65 GB；系统当前支持休眠和快速启动，且 `HiberbootEnabled=1`。
- E 盘约有 172.8 GB 空闲，可作为下载资料的迁移目标，但尚未执行搬运。

## 决策与依据

- 采用先盘点、再分级处理的低风险策略；保留下载目录中的工程源资料和测试证据。
- 未直接删除用户临时目录：当前执行环境的文件保护策略拒绝了递归删除命令，未使用变形命令绕过。
- 已运行 Windows 自带磁盘清理（`cleanmgr /verylowdisk /d C:`），退出码为 0，但用户临时目录仍约 7.99 GB，释放空间不明显。
- 关闭休眠可释放约 12.65 GB，但会改变休眠和快速启动功能，需用户明确确认后再做。

## 操作与产物

- 完成 C 盘容量、临时目录、下载目录、浏览器缓存和根目录大文件的只读盘点。
- 未修改、删除或移动下载资料、工程目录、知识库和现有 `.obsidian/graph.json` 改动。

## 待确认或待实测

- 是否关闭休眠以释放 `hiberfil.sys` 占用。
- 是否把下载目录中确认不常用的 CAD 安装包、旧压缩包或重复交付包搬到 E 盘；搬运前应逐项确认用途和备份状态。
- 用户临时目录需要在文件保护允许的情况下清理，清理时应跳过正在使用的文件。

## 可复用知识

1. C 盘清理应先区分系统大文件、缓存、下载资料和路径敏感工程目录。
2. `hiberfil.sys` 是高收益但会改变系统行为的清理项；不能当作普通缓存直接删除。
3. 下载目录中的固件、PCB、报告和安装包可能是工作证据或可复现资料，优先搬运而不是删除。
