# 产品与技术路线图

## MVP：先做可靠闭环

- 单设备绑定、扫描、自动重连。
- PING、时间同步、设备信息与能力查询。
- Today、时钟、便签、照片卡。
- 400×300 最终预览和黑/红平面检查。
- 真实发送进度、错误恢复、历史持久化。
- 清屏、三色测试图、日志导出。
- 近场 Secure DFU Beta。

## V1.1：提升复用和差异化

- 定时发送与离线发送队列。
- 模板收藏、自定义模板和历史搜索。
- 天气日历、答案之书。
- 外置 Flash 多页缓存。
- 开发者模式：JEDEC、晶振、RSSI 和诊断报告。
- 受控的黑白动画实验。

## V2：硬件产品化

- 电池、充电和真实电量采样。
- 正式 5 V 电源入口与检测。
- 天线和地优化，提升 OTA 距离和稳定性。
- 量产测试点、外壳、按键和设备身份。
- 多设备、家庭共享和可选云同步。

## 技术债优先级

| 优先级 | 项目 | 完成标准 |
|---|---|---|
| P0 | 实板回归 v1.0.0 | PING/INFO/TIME/TEST/IMAGE 全链路通过 |
| P0 | Android 真 BLE 接入 | 不再使用静态设备信息和虚假电量 |
| P0 | OTA 稳定性 | 稳定供电、近场成功率达到产品目标 |
| P1 | 数据持久化 | 草稿、历史、绑定和设置跨重启保存 |
| P1 | 设备诊断 | 一份报告可区分连接、供电、显示和 OTA 问题 |
| P2 | 外置 Flash 缓存 | 不破坏用户数据的容量与读写测试 |
